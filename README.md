# Antistress — 7 игрушек

Красивый антистресс для телефона и компьютера. Без лагов: движок на `requestAnimationFrame` с `dt`-физикой (60/120/144Hz), предрендер 3D-спрайтов, Full HD-минимум по ширине.

Игрушки: **Поп-ит · Пупырка · Пузыри · Слайм · Нарезка мыла · Шарики · Кинетический песок**

Плюс: 3 темы (Закат/Океан/Неон), RU/EN, звук-синтез WebAudio, вибрация, PWA-manifest.

## Запуск локально
```bash
python -m http.server 8000
# открыть http://localhost:8000/
```

## GitHub Pages
Ветка `main`, корень `/`. После пуша: Settings → Pages → Deploy from branch → `main` / `(root)` → открыть `https://<user>.github.io/Antistress/`.

Горячие клавиши: `1..7` режимы, `R` заново, `M` звук, `T` тема, `L` язык, `F` полный экран.
